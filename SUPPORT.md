# Support

AlgoForge is an independent development-stage project. For help:

- Check the setup and troubleshooting sections in `README.md`.
- Review `IMPLEMENTATION_STATUS.md` and `docs/PRODUCTION_READINESS.md` for known limitations.
- Open a GitHub issue for reproducible non-security bugs or feature requests.
- Do not post secrets, personal information, private submissions or vulnerability details in public issues. Follow `SECURITY.md` for security reports.

No uptime, response-time or support SLA is provided for self-hosted deployments.
