# GitHub and open learning resources

The following resources were reviewed as learning references. They are not all problem-bank sources, and their existence does not grant redistribution rights to third-party problems linked from them.

| Resource | Why it is useful | Treatment in AlgoForge |
|---|---|---|
| [TheAlgorithms organisation](https://github.com/TheAlgorithms) | Readable algorithm/data-structure implementations across Python, Java, C, C++ and other languages; the organisation page identifies language repositories and MIT licences for several repositories | Use for internal learning/reference links; no wholesale copy into the product |
| [cp-algorithms](https://github.com/cp-algorithms/cp-algorithms) | In-depth competitive-programming algorithms and data-structure articles; repository reports CC BY-SA 4.0 | Link as a study reference; any adaptation must follow CC BY-SA 4.0 attribution/share-alike terms |
| [Striver A2Z DSA Sheet community mirror](https://github.com/Codensity30/Strivers-A2Z-DSA-Sheet) | Topic-organised sheet with problem names and approach files | Discovery only; inspect per-repository licence and each linked platform's rights before importing |
| [Striver A2Z sheet tracker](https://github.com/geckguy/striver-a2z-sheet) | Reports a 402-question tracker with platform links and pattern/module grouping | Useful for validating topic coverage; not treated as an official API or permission to redistribute |
| [Striver learning-sheet archive](https://github.com/ThatDeparted2061/Striver-DSA-Resources) | Lists archived sheets, links and difficulty information | Metadata discovery only; do not mirror proprietary content |
| [Codeforces official API](https://codeforces.com/apiHelp/methods?locale=en) | Public problem metadata and statistics for a reproducible import | Used by `scripts/import_codeforces.py` |

## Import policy

- Keep source URL and source platform for every record.
- Keep licence/provenance information when content is reused.
- Never import a solution, statement or editorial just because a GitHub repository is public.
- Recheck repository licence, owner and current status at import time.
- Prefer metadata plus canonical link where permission is unclear.
